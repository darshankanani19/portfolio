# Darshan Apps Portfolio

A premium, fast, and SEO-optimized web portfolio built to resemble a Mini Google Play Store.

## Features
- **Dark & Light Mode**: Seamless toggling using CSS variables and Vanilla JS.
- **App Store Architecture**: A main storefront with categorized app cards, filtering logic, and dedicated detail pages.
- **Glassmorphism UI**: Beautiful frosted glass effects using backdrop-filter.
- **Detail Pages**: Fully fledged product pages with screenshot carousels, feature grids, and app info tables.
- **SEO Optimized**: Includes `sitemap.xml`, `robots.txt`, and standard meta tags.
- **No Dependencies**: Built using pure HTML, CSS, and JS. Easily deployable to GitHub Pages.

## Included Apps
1. Smart Shop Manager
2. Magic Doodle Kids
3. Sudoku
4. ArrowLoom

## Setup & Deployment
Since this is a static site, you can directly open `index.html` in your browser. 
To host it, push this folder to a GitHub repository and enable GitHub Pages in the repository settings.
